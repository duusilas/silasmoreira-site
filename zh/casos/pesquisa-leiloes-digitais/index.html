Platform Experience，数字拍卖

在成千上万的选择中找到合适的车辆。

二手车数字拍卖：如何在不同市场连接搜索、信息与购买体验。

业务背景。

拍卖买家寻找的是适合自己生意的机会，而不只是一辆车。他们需要足够了解每辆车的车况和条件。

当车源横跨属性、数据和展示方式各不相同的市场时，挑战更大。

我的角色。

我负责买家的搜索旅程、搜索界面的重新设计，以及信息 API 的演进。

我与设计和工程团队协调欧洲各市场的上线，兼顾各市场在数据和运营上的差异。

体验背后的决策。

从买家的决策出发

了解他们如何缩小选择范围、什么信息会让他们点进车辆详情，让筛选与真实任务挂钩。

数据是体验的一部分

筛选只有在属性一致时才有用：统一的术语、处理不完整数据的规则，以及界面与 API 之间清晰的关系。

一致性与本地化

统一语言、交互模式和属性含义，同时不抹去市场之间的真实差异。

可持续学习的交付

功能验证、数据质量和旅程分析，找出无结果的搜索和不再有用的筛选。

结果

交付

交付内容

如何验证

如何把结构落地交付。

  1. 梳理任务

    买家如何缩小选择并做决定。

  2. 对齐信息契约

    界面与 API 之间的属性、术语和规则。

  3. 验证完整体验

    从搜索到比较，使用真实数据。

  4. 跟进上线

    逐个市场，对照基线。

上线后要关注什么。

搜索连接意图、信息与决策。产品的职责是在不同情境中把这些部分连接起来。

可发现性

无结果的搜索和重新搜索。

清晰度

对属性的理解，以及能否进入有依据的评估。

可靠性

数据一致性、错误和响应时间。
